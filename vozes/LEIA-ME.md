# Vozes do jogo

Coloque aqui arquivos **.mp3** com exatamente estes nomes. O jogo usa o arquivo
automaticamente no lugar da voz sintetizada, para todo mundo que abrir o link.

| Arquivo | Personagem | Fala mostrada no balão |
| --- | --- | --- |
| `lula_pegar.mp3` | Lula | Vou te pegar, Flávio! |
| `lula_volta.mp3` | Lula | Volta aqui, companheiro! |
| `lula_correr.mp3` | Lula | Não adianta correr! |
| `lula_peguei.mp3` | Lula | Peguei você! (quando ele te alcança) |
| `lula_aviao.mp3` | Lula | Esse avião não vai sair! (quando o avião decola) |
| `flavio_passaporte.mp3` | Flávio | Não vai pegar meu passaporte! |
| `flavio_ninguem.mp3` | Flávio | Ninguém me pega! |
| `flavio_fui.mp3` | Flávio | Fui! Tchau, Brasil! (ao embarcar) |
| `flavio_ai.mp3` | Flávio | Ai! (quando leva dano) |
| `militante_olha.mp3` | Militante | Olha ele ali! Pega! |
| `militante_anistia.mp3` | Militante | Sem anistia! |
| `pf_parado.mp3` | Polícia Federal | Polícia Federal! Parado aí! |
| `pf_mandado.mp3` | Polícia Federal | Temos um mandado! |
| `cf_iguais.mp3` | Constituição | Todos são iguais perante a lei! |
| `cf_acima.mp3` | Constituição | Ninguém está acima da Constituição! |

Dicas:
- Áudios curtos (1 a 3 segundos) funcionam melhor.
- Não precisa ter todos: o que faltar continua com a voz do celular.
- Se o áudio disser outra frase, troque o texto do balão em `audio.js` (lista `LINES`).
- Para converter outros formatos para mp3, qualquer conversor online de áudio serve.
